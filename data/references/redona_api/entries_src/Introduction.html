Introduction
Redona API provides interface to interact with Redona Engine. It is how it can be easily integrated within application. Further text will explain you some general stuff which can be helpful with reading whole left content in this page. API is written in C++23.
Name prefix expansions
I_
Interface
E_
Enumeration
C_
Concept
IF_
Info
Namespaces
All symbols are defined in rdn namespace excepting preprocessor macros, which starts with RDN_ prefix. app namespace is reserved for application itself.
