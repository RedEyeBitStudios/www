This reference describes the API of Redona Engine, referred to as RDN API. Written in C++26 it allows the application developer to interact with the mentioned earlier engine. RDN API is part of Redona SDK.

Name prefixes

I_ Interface
Interface class that provides some logic.
E_ Enumeration
This is as simple as a regular enum/enum class in standard C++.
C_ Concept
This is as simple as a regular concept in standard C++.
IF_ Info
Structure that contains data only. Designated initializer guaranteed.

Namespaces

All symbols are defined in the rdn namespace. Exceptions here are preprocessor macros which start with RDN_ prefix. Application dedicated namespace is app.

In code name casing

snake_case - variables
- function arguments (even if they are const qualified)
PascalCase - every struct
- every class
- every enum
- every enum class
- every concept
- every type alias
UPPER_CASE - compile-time constants
- enum/enum class values
- preprocessor macros
- template arguments
camelCase - function
- lambda
- class function member (excepting destructor and constructors)
